# Cross-family semantic experiments

Based on one instance of `give_coin:true` for Qwen 2.5 3B in an 18-prompt screen and five instances in a subsequent 48-response study.

The underlying hypothesis is not that the real wizard should give away the coin, but that an LLM may mistakenly fill the contract's action Boolean with the answer to a **fictional reading-comprehension label**, despite reasoning to keep the real coin.

These eight 1,000-character-safe messages will be tested against Qwen 2.5 3B, Gemma 3 4B, and Phi-3 Mini twice each. A true result is useful only if it is parseable, consistent, and validated by independent models; local model agreement is still not on-chain GenLayer consensus.

No wallet keys, Studio Next, test GEN, or paid APIs are used.
